# Steam Currency → RUB Конвертер

Расширение для браузера (Chrome, Edge, Brave), которое автоматически конвертирует **любые цены на Steam** в рубли (₽).

Поддерживаемые валюты: тенге (₸), доллар США ($), евро (€), фунт (£), турецкая лира (₺), украинская гривна (₴), польский злотый (zł), китайский юань (¥), индийская рупия (₹), бразильский реал (R$), корейская вона (₩), швейцарский франк (Fr), канадский доллар (C$), австралийский доллар (A$), мексиканский песо (MX$), сингапурский доллар (S$), гонконгский доллар (HK$), тайваньский доллар (NT$), тайский бат (฿).

## Установка

1. Скачайте все файлы расширения в одну папку на компьютере.
2. Откройте браузер и перейдите по адресу `chrome://extensions/` (для Edge — `edge://extensions/`).
3. Включите **«Режим разработчика»** (переключатель в правом верхнем углу).
4. Нажмите **«Загрузить распакованное расширение»**.
5. Выберите папку с файлами расширения.
6. Готово! Откройте Steam — любые цены в иностранной валюте будут автоматически конвертироваться в рубли.

## Как это работает

- На любой странице Steam (магазин, поиск, страница игры, корзина) рядом с ценой в любой иностранной валюте появится эквивалент в рублях.
- Курс валют загружается с открытого API `open.er-api.com` и обновляется автоматически каждый час.
- История курсов сохраняется в базе данных Supabase для отслеживания изменений.
- Нажмите на иконку расширения в панели браузера, чтобы увидеть курсы всех валют и обновить их вручную.

## Файлы

| Файл | Назначение |
|------|-----------|
| `manifest.json` | Манифест расширения (Manifest V3) |
| `background.js` | Фоновый скрипт — загрузка и кэширование курсов всех валют |
| `content.js` | Контентный скрипт — поиск цен в любой валюте и конвертация в рубли |
| `styles.css` | Стили для отображения конвертированных цен |
| `popup.html` / `popup.css` / `popup.js` | Всплывающее окно со списком курсов всех валют |
| `currencies.js` | Описание поддерживаемых валют и их символов |
